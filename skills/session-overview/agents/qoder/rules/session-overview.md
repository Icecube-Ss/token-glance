# 会话概览规则（Mode B）

当用户要求「会话概览 / 会话视图 / 当前会话状态 / session overview」时，输出一份一屏可读完的会话概览。

## 依据

- 只使用本次会话中出现的事实，以及本次会话中实际读过的文件。
- 能读仓库时，优先读同目录 `SKILL.md` 与 `references/mode-b-report.md`，按其中规范执行。

## 硬性要求

- 无法测量的数字一律写 `unavailable`，不得估算轮次、token、耗时、百分比。
- 不写无证据的形容词；不承诺未被要求的后续工作。
- 全文控制在约 250 字/一屏；路径带行号（如 `src/app.ts:42`）。

## 输出格式

```markdown
## 会话概览

**目标** — 一句话说明本次会话要达成什么。
**状态** — 运行中 · 实现阶段
**已测量** — 改动文件 3 · 执行测试 1 · token 用量 unavailable

### 已完成
- `path:line` — 做了什么 / 跑过什么命令 / 定下了什么结论

### 进行中
- 当前正在做的那一步

### 下一步
1. 具体动作

### 阻塞项
- 真实阻塞，或写「无」

### 关键文件
- `path:line` — 为什么重要
```
